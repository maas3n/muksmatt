# muKsMaTT v0.1.0-beta.1 — public testing beta

**Experimental prerelease.** This build is for volunteer compatibility testing, not a stable production release. Keep your original discs and source files safe; do not treat the generated MKV as your only copy.

muKsMaTT provides DVD remux/demux workflows and developing Blu-ray-to-MKV support on Windows, Linux and Android/ChromeOS. The app originates from MattRip/MattMux but uses its own release and Android signing identity.

## Downloads

All packages below are built from the same version tag. Verify each download against `SHA256SUMS.txt` on this GitHub Release before installing.

- **Windows:** `muKsMaTT-0.1.0-beta.1-Windows-All-in-One.exe`, Windows Setup executable, or Windows Portable ZIP.
- **Linux x86-64:** `muKsMaTT-0.1.0-beta.1-Linux-amd64Standalone` (make executable with `chmod +x`), Debian `.deb`, or Linux tarball.
- **Android / ChromeOS:** `muKsMaTT-0.1.0-beta.1-Android.apk` is the signed direct-download APK. Chromebook support requires Android app capability. This is **not** a Google Play release.

## Verify package SHA-256 before installing

After authorized publication, compare the SHA-256 of the **exact downloaded beta asset** to its entry in the release's `SHA256SUMS.txt`. On Linux, run `sha256sum muKsMaTT-0.1.0-beta.1-Linux-amd64Standalone` (or the filename you downloaded) and compare the 64-character digest. On Windows, run `Get-FileHash -Algorithm SHA256 .\\muKsMaTT-0.1.0-beta.1-Windows-All-in-One.exe` in PowerShell and compare the result. You can verify the downloaded Android APK the same way on your computer. Do not use old development-rehearsal hashes.

## What automated testing has covered

- Windows, Linux and Android/ChromeOS build and regression workflows passed for the merged Blu-ray development baseline.
- Self-authored **unencrypted** BDMV folders and Blu-ray ISO fixtures have been processed in native tests; Linux desktop CLI has also been tested end to end.
- Automated validation covered playlist scanning, stream selection, chapters and lossless PCM-to-FLAC sample parity on authored fixtures.
- DVD remux/demux regression tests remain part of the CI suite.

Passing CI is not evidence that physical Blu-ray drives, all Blu-ray titles or real protected discs work.

## Compatibility testing requested

**Highest priority: volunteers with real optical Blu-ray drives on Windows or Linux.** Please try unencrypted discs or your own authorized backups first. Test BDMV folders and Blu-ray ISO files separately, and compare results to normal playback. Report chapters, selected streams, subtitles and A/V sync, especially at playlist/clip boundaries.

Windows/Linux command-line testers can use the packaged `muksmatt-cli` (`muksmatt-cli.exe` on Windows):

```text
muksmatt-cli bluray scan SOURCE
muksmatt-cli bluray remux --output OUTPUT.mkv SOURCE
```

Replace `SOURCE` with the real folder, ISO or supported drive/device path. Ensure enough space and choose an output path different from the source. Verify the resulting MKV in a media player. For step-by-step test cases, platform notes and a copy-ready issue report, see the [Community beta testing guide](https://github.com/maas3n/muksmatt/blob/main/docs/releases/v0.1.0-beta.1-testing.md). For technical verification details, see the [Real-media validation checklist](https://github.com/maas3n/muksmatt/blob/main/docs/BLURAY_REAL_MEDIA_VALIDATION.md).

## Known limitations and unverified features

- **Physical Blu-ray drives:** not yet validated against real hardware on Windows/Linux.
- **Protected Blu-ray discs (AACS and BD+):** functionality and decryption success not verified; bundled libraries alone do not establish decryption support. Failed protection checks must not be mistaken for success.
- **Android/ChromeOS:** native Blu-ray BDMV/ISO remux is experimental; external USB Blu-ray optical-drive support is **not validated or claimed as supported**. Android Blu-ray GUI integration and real-device support may need further work.
- **Blu-ray short titles:** FFmpeg's desktop `bluray:` protocol may reject titles shorter than 180 seconds; see [issue #20](https://github.com/maas3n/muksmatt/issues/20).
- **Codec/media coverage:** commercial authoring variants, seamless branching, multichannel/high-definition audio, PGS subtitling and protected sources still require real-media testing.

## Report a test result

Please [open a GitHub issue](https://github.com/maas3n/muksmatt/issues/new) with a clear title such as `[Blu-ray beta] Windows 11 / USB drive / ISO remux`. Include:

- OS and architecture; muKsMaTT version; package type.
- Blu-ray reader model and connection type (internal/USB), if applicable.
- Source type: real disc / BDMV folder / ISO; encrypted or unencrypted if known.
- Playlist selection and duration, video/audio/subtitle codecs, selected streams and chapter count.
- Expected vs actual result, remux errors or crashes, playback and audio/video sync observations.
- Reproduction steps and **sanitized** command output or logs.

**Privacy and copyright:** Do not upload full discs, copyrighted video/audio excerpts, private filesystem paths, device identifiers, decryption keys, certificates, Android signing material or passwords. Use your own legally accessible test media, and comply with local law. Do not include personally identifying disc names if unnecessary.

This prerelease is intended to collect reports and guide follow-up fixes. Production compatibility claims will require independent hardware evidence.
